# React Demo

这是一个最小 React + Vite 演示壳，用来展示“不同时间段的宠物模块背景”。

## 目录

- `src/components/TimePetBackground.jsx`
- `src/components/TimePetBackground.css`
- `src/App.jsx`

## 启动

先安装依赖：

```bash
npm install
```

开发启动：

```bash
npm run dev
```

## 当前能力

- 晨曦 / 上午 / 下午 / 夜晚 四个时段主题
- 粒子漂浮动画
- 儿童向的亮色氛围与宠物能量核心
- 响应式布局
